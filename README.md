# 🚗 CarDekho – Used Car Price Prediction Model
A Machine Learning project that predicts used car prices using Random Forest Regression, Python, and Flask based on vehicle features and specifications.

## 📌 Project Overview
The CarDekho Car Price Prediction Model is a Machine Learning project developed to predict the resale value of used cars based on various vehicle characteristics. The project uses historical car sales data to understand pricing patterns and estimate the expected market value of a vehicle.

The model is developed using Python and Random Forest Regression, with Flask used to create a web-based interface for making predictions.

## 🎯 Project Objectives
- To predict the resale price of used cars using Machine Learning.
- To analyze the factors influencing used car prices.
- To perform data cleaning and preprocessing on real-world datasets.
- To identify important features affecting vehicle resale value.
- To develop a predictive model using Random Forest Regression.
- To provide an easy-to-use interface for estimating car prices.

## ⚙️ Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Algorithm:** Random Forest Regression
- **Web Framework:** Flask
- **Development Environment:** Jupyter Notebook / VS Code

## 📊 Dataset Description
The dataset contains information about used cars, including:
- Car Name / Model
- Manufacturing Year
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission Type
- Number of Previous Owners

These attributes are used to train the machine learning model and predict the estimated resale price.

## 🔄 Project Workflow

1. **Data Collection:** Loading the used car dataset.
2. **Data Preprocessing:** Handling missing values, duplicate records, and inconsistent data.
3. **Exploratory Data Analysis (EDA):** Understanding data distributions and relationships between car features and selling prices.
4. **Feature Engineering:** Preparing categorical and numerical variables for model training.
5. **Model Building:** Training the Random Forest Regression algorithm.
6. **Model Evaluation:** Evaluating model performance using suitable regression metrics.
7. **Model Deployment:** Integrating the trained model with Flask to enable user-based predictions.
